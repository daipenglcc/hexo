以前写个文档或者博客，还得打开 Word 弄半天字体和段落对齐，一换电脑格式全乱套。后来用了 Markdown，发现纯文本简直是世界上最伟大的发明之一，双手不用离开键盘就能搞定排版。

现在不管是在 Github 上写 README、在博客里记笔记，甚至平时的任务清单，全靠它。语法就那么几条，但一阵子不写容易把表格或者代码块的符号忘掉，干脆写个速查表扔在这里。

<!--more-->

## 1. 最常用的：写字和列点

### 标题就是打井号
几个井号就是几级标题，记得井号后面要加个空格：

```markdown
# 我是一级标题（字最大，一般当主标题用）
## 我是二级标题
### 我是三级标题
```

### 粗体和斜体
两边加星号就行，粗暴简单：

```markdown
平时说话，**划重点**的地方加两个星号。
偶尔*骚一下*用斜体就加一个星号。
写错了的东西直接~~删掉重来~~用两根波浪线。
```

### 列表不用自己敲数字
遇到要列点列条目的，随便敲个横杠 ` - ` 它就自动识别了：

```markdown
出去玩要带的东西：
- 身份证
- 钱
- 手机
  - 充电宝（前面敲两个空格就能变成子级）
```
如果你非要按数字排，就直接打 `1. `、`2. `，它也能认。

## 2. 程序员的最爱：插代码块

如果你写的一段话里有个单词想高亮（比如变量名），用键盘左上角 Esc 下面那个反引号 `` ` `` 包起来：

```markdown
请运行 `npm run dev` 启动项目。
```

如果是整块的代码，就敲三个反引号，顺便在后面写上是什么语言，它就会自动给你套上高亮的颜色：

````markdown
```javascript
function hello() {
  console.log("这排版，看着就清爽");
}
```
````

## 3. 引用别人说的话

写博客的时候遇到名人名言，加个大于号 `>`：

```markdown
> 鲁迅曾经说过：其实地上本没有路，走的人多了，也便成了路。
```

## 4. 插入链接和图片

这是最容易搞混的一个，两者的区别就是图片多一个感叹号 `!`。格式都是：`[文字](网址)`。

```markdown
<!-- 这是一个可以点过去的外链 -->
强烈推荐逛逛我的[光阴小栈](https://www.vueweb.cn/)

<!-- 插入一张表情包，感叹号打头 -->
![震惊猫猫图](https://www.vueweb.cn/images/cat.jpg)
```

## 5. 永远记不住的画表格

这是 Markdown 里最累人的一个，每次我都是一边敲空格一边对齐。

```markdown
| 快捷键 | 功能 | 好用程度 |
| :--- | :---: | ---: |
| Ctrl+C | 复制 | ⭐️⭐️⭐️ |
| Ctrl+V | 粘贴 | ⭐️⭐️⭐️⭐️⭐️ |

<!-- 顺便提一句对齐的玄机：
冒号在左边 `:---` 就是左对齐
冒号在两边 `:---:` 就是居中
冒号在右边 `---:` 就是右对齐
-->
```

## 6. 做个打钩的 CheckList

用来做 TODO list 最方便，写在备忘录里每天打钩：

```markdown
今天干嘛：
- [x] 写三行代码
- [x] 下楼拿个外卖
- [ ] 修复昨天的那个惊天大 bug
```
*(注意：中括号里面敲个 x 就是完成了，敲个空格就是还没干。)*

基本就这些了。现在用 VS Code 配合个 `Markdown All in One` 的插件，或者直接下个 `Typora`，写完立马就能在旁边看到漂亮的排版，体验简直能秒杀一众传统办公软件。
