写作利器：Markdown 高频语法速查

发表于 2016-11-27 | 更新于 2026-09-23 | 分类于 Markdown | 评论数： — | 阅读次数：

以前写个文档或者博客，还得打开 Word 弄半天字体和段落对齐，一换电脑格式全乱套。后来用了 Markdown，发现纯文本简直是世界上最伟大的发明之一，双手不用离开键盘就能搞定排版。

现在不管是在 Github 上写 README、在博客里记笔记，甚至平时的任务清单，全靠它。语法就那么几条，但一阵子不写容易把表格或者代码块的符号忘掉，干脆写个速查表扔在这里。
